# ⚡ Minimalist Monochromatic Cloud & DevOps Portfolio

A lightweight, hand-crafted Cloud & DevOps Engineer Portfolio built strictly with **HTML5, CSS3, and JavaScript (ES6+)**. Zero frameworks, zero dependencies, instant page load speed!

---

## 📁 File Structure

```
portfolio/
├── index.html       # Complete HTML5 structure & content
├── styles.css       # Complete CSS design system, floating pill dock, & print styles
├── script.js        # Pure Vanilla JS (typewriter animation, scroll navbar, live API sync)
└── README.md
```

---

## 🌟 Key Features

1. **⌨️ Typewriter Animation on Load**:
   - Types out:
     > **Hi, I'm <u>Jatin</u>.**
     > **Cloud & DevOps Engineer**
   - Role Bullet Line: **Aspiring Cloud Engineer • DevOps • Infrastructure Automation**

2. **🚀 Floating Rounded Pill Dock Navbar on Scroll**:
   - Navbar dynamically shrinks into a floating centered pill dock (`border-radius: 9999px`) on scroll with glassmorphism backdrop blur.

3. **⚡ Side-by-Side Live Stats Sync**:
   - Directly fetches live public statistics from GitHub REST API (`https://api.github.com/users/jatins2405`) and LeetCode Stats API (`https://leetcode-stats-api.herokuapp.com/jatins2405`).

4. **📄 Printable Executive CV Modal**:
   - One-click **Print / Save PDF** modal trigger (`window.print()`).

5. **💻 Developer CLI Terminal Drawer**:
   - Interactive bottom drawer supporting `help`, `about`, `skills`, `internships`, `projects`, `github`, `leetcode`, `contact`, and `clear`.

6. **✉️ Contact & Email Copy Widget**:
   - One-click copy for `jatinsharma24062005@gmail.com` plus interactive message form.

## 🚀 How to Run

Simply open **`index.html`** in any web browser by double-clicking the file! No installation or build steps required.
